What is Pausen, and is this the official Android APK?+

Pausen is a free Android app developed by Approxy-dev for bedtime schedules, breathing scroll pauses, and warm reading. This is the official Pausen website. The signed Pausen v1.10.2 APK is available here and on Approxy-dev's GitHub Releases for Android 10 and newer. Its Android package ID is com.sleepguardian.app.

Is Pausen APK related to SleepGuardian APK?+

Yes. Pausen was previously developed as SleepGuardian Mobile. The Android app is now named Pausen; its package ID remains com.sleepguardian.app so compatible signed updates can preserve existing local data.

How does Pausen work as a bedtime app and scroll pause app?+

As a bedtime app, Pausen lets you schedule automatic evening wind-downs, warm screen tints, and strict bedtime curfews. As a scroll pause app, it detects continuous scrolling sessions in social media feeds and triggers a calming 12-second breathing pause with an optional 24-hour commitment lock.

How do I download and install Pausen APK on Android?+

Download the signed Pausen APK (v1.10.2) directly from this website or the GitHub releases repository. Tap the downloaded file in your browser's Downloads folder, grant Allow from this source in Android Settings if prompted, and follow the on-screen setup to complete installation on any phone running Android 10 or newer.

Is Pausen APK completely safe, free, and private?+

Yes, Pausen is 100% free and private. Its Android manifest does not request internet access (the INTERNET permission is completely omitted). All your bedtime plans, app limits, and history remain strictly on your phone in a local SQLite database with zero tracking and zero telemetry.

What Android versions does Pausen support?+

Pausen supports Android 10 (API 29) and newer, including Android 11, 12, 13, 14, and 15+.

Why is Pausen distributed as an APK rather than Google Play?+

The official Pausen v1.10.2 release is distributed here and through Approxy-dev's GitHub Releases as a signed APK. It is free to download. Direct APK distribution is separate from the app's offline privacy design.

Android 13+: “Restricted setting” when enabling Accessibility?+

If you trust the downloaded app, go to Settings → Apps → Pausen → More (⋮) → Allow restricted settings and confirm your identity. Then return to Settings → Accessibility → Pausen to enable the service.

Names and availability vary by Android version and manufacturer. Accessibility lets Pausen identify the active app and show its protection screens. Read the permission explanation before enabling it.

What if Google Play Protect shows a warning?+

Play Protect may offer a scan for an unfamiliar APK. Keep it enabled and review the result. Some prompts offer More details → Install anyway; that option is not available for every warning or device. Only continue if you trust the source and understand the warning.

If the app is flagged as harmful or installation remains blocked, stop and contact the developer with the warning text. A download from this page is not a guarantee that a device’s security checks will accept it.

What should I know before applying a plan?+

Applied bedtime plans are fixed in the app. Review the times, days, duration, and allowed apps first. Turning on Scroll Pause locks its settings for 24 hours; strict mode has its own waiting period.

During protected periods, Pausen can guard Settings and uninstall screens. Accessibility and background access are needed for protection. Android Force stop can stop the app; device battery management can interrupt it. The app is a self-control aid, not a tamper-proof device manager.

How do I verify the download or update Pausen?+

Install this signed release over an existing release signed with the same certificate to preserve compatible local records. A debug build may have a different signature. Uninstalling or clearing app storage deletes local data.
